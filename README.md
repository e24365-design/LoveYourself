# LoveYourself – upload guide
Upload ALL files in this folder to the ROOT of your repo (no folders), next to your existing stickers.
- Let index.html, mood.html, mood.js, win.html, jar.html, jar.js, common.js, pages.css replace the old ones.
- New: deco.js (blinking stickers) and many ly_ image files (jars, months, kawaii stickers).
- Delete `index .html` (with a space) and the old `mood.css` from the repo.
- Hard-refresh after upload (Ctrl+Shift+R, or reload twice on phone).
