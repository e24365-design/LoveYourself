# LoveYourself – upload guide
Everything is now FLAT (no folders). Upload ALL files in this folder into the ROOT of your repo, next to your existing stickers.
- index.html MUST replace the old index.html (your tabs only change after this).
- Delete `index .html` (has a space) and old `mood.css`.
- After upload, wait ~1 minute and hard-refresh (Ctrl+Shift+R, or reload twice on phone).
- Files starting with ly_ are the cut-out jars, month stickers and flowers.
